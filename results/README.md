# Results

This directory contains curated outputs from the completed runs.

`tables/` stores the uploaded CSV metrics. `loso_all.csv` is the primary subject-held-out benchmark table. `design_comparison.csv` contains the force and torque architecture ablation. `extensions_clean.csv` and `extensions_occlusion.csv` contain physics and corruption experiments.

`figures/` stores qualitative outputs used in the project documentation. The selected figures avoid the optional single-photo illustration because that path is not validated against dynamics ground truth.
